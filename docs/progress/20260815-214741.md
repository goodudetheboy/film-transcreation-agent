# 2026-08-15 21:47 — Test mode (mock data path)

## What changed

- Added a "Test mode" checkbox to the frontend form, **checked by default**, per
  user request. Lets anyone run the full UI flow without Google Cloud credentials
  or spending Dialogflow CX quota.
- `backend/src/services/mockDialogflowClient.ts` — canned `DialogflowClient`
  implementation. Content reuses the two documented real cases from the pitch
  (Pixar's Inside Out broccoli→green-pepper swap, a US-specific DMV reference)
  rather than inventing scenarios, matching the pitch's own instruction to use
  verifiable published cases.
- `backend/src/routes/analyze.ts` now picks between the real and mock
  `DialogflowClient` per request based on a `testMode` field in the body — defaults
  to mock unless `testMode` is explicitly `false`, so a caller that forgets the flag
  never accidentally hits the real paid API.
- `frontend/src/api/apiClient.ts`'s `StreamAnalyzePayload` gained a required
  `testMode: boolean` field; `App.tsx` wires it to the new checkbox.
- Updated `docs/adr/0005`'s existing pattern of one seam serving both tests and this
  new runtime switch, and added `docs/adr/0010-test-mode-mock-data.md` recording the
  decision, including the explicit warning that the real demo moment requires
  remembering to uncheck the box.
- Built test-first throughout: `mockDialogflowClient.test.ts`, three new
  `analyzeRoute.test.ts` cases (defaults to mock when omitted; explicit true; explicit
  false — each asserting the *other* client was never called), updated
  `apiClient.test.ts`'s body-shape assertion, and updated the integration suite's
  three requests to pass `testMode: false` explicitly so they keep exercising the
  real (faked) `dialogflowClient` path end-to-end rather than silently switching to
  testing the new mock path instead.
- Verified live in the browser: default (checked) → mock data streams back
  instantly, styled correctly as result cards; unchecked → hits the real
  `dialogflowClient` path and correctly surfaces the same ADC error as before
  (proving both branches of the switch work, not just the mock one).
