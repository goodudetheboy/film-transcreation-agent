## Decisions made (and where they're recorded)

- **`dev.sh`'s cleanup had a real bug, found and fixed by testing it, not just
  writing it.** First version killed by PID and by port; testing revealed that on
  Windows, `npm run dev:X &` spawns a process *tree* (npm → npm -w X → tsx/vite),
  and killing only the top PID or only the port-bound leaf process leaves the
  middle wrapper processes orphaned — reproduced the exact same leftover-process
  issue that bit the manual smoke tests earlier this session. Fixed by using
  `taskkill //F //T //PID` (Windows tree-kill) as the primary cleanup mechanism,
  with the PID/port-based approach kept only as a last-resort fallback. Verified
  by starting the script, then tree-killing the wrapper PIDs the same way the
  script's own `kill_tree` function does, and confirming zero node processes and
  both ports fully free afterward.
