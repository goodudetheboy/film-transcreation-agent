## 22:41 — Chat tool-call cards no longer show raw snake_case names

User flagged mid-task, sent alongside the admin work above: tool names
showing as literal `update_rubric_score` in the agent chat instead of
something humanized like "Update Rubric Score". Reading
[ResearchChatPanel.tsx](../../frontend/src/components/ResearchChatPanel.tsx)'s
`ToolCallCard` found the actual bug: the in-flight state already had a
friendly label per tool via `toolStepLabel()` ("Updating a rubric score…"),
but the completed (checkmark) state had no equivalent — it fell straight
through to `{name}`, the raw function name, for every mutation tool
(`update_rubric_score`/`propose_replacement`/`update_assessment`). Added a
`toolCompletedLabel()` counterpart with past-tense text for those three.
[DiscoveryChatPanel.tsx](../../frontend/src/components/DiscoveryChatPanel.tsx)'s
own `DiscoveryToolCallCard` already had a complete, correct label mapping for
both states — its only gap was the fallback for a tool with no specific
label (`Called ${name}`), same class of gap as `toolStepLabel`'s own
fallback in the other panel.

New shared [humanizeToolName.ts](../../frontend/src/utils/humanizeToolName.ts)
(`update_rubric_score` → `Update Rubric Score`) used as that fallback in
both panels, so a tool added later without matching copy still reads as
words instead of a code symbol, rather than hand-copying the same
split/capitalize logic into both files. New
[humanizeToolName.test.ts](../../frontend/src/utils/humanizeToolName.test.ts)
covers the multi-word and single-word cases. No new ADR — a UI-copy fix. No
existing test file covers either chat panel component (neither
`ResearchChatPanel.test.tsx` nor `DiscoveryChatPanel.test.tsx` exist), so
this only has coverage on the new pure util, not the two call sites
themselves — worth a manual check next time either panel runs a mutation
tool live. Verified: `tsc -p tsconfig.app.json --noEmit` clean, `npx vitest
run` 85/85 (2 new). Not live-walked via the dev servers, per this session's
established pattern of the user driving them directly.
